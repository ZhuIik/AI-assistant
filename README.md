# AI-Assistant — локальный учебный RAG-ассистент

Ассистент для ответов на вопросы по материалам курса (лекции, семинары, пособия). Полностью офлайн: аудио транскрибируется, размечается, индексируется, а ответы формируются локальной LLM поверх найденного контекста — без дообучения модели под каждый курс.

Целевой сценарий: преподаватель загружает записи своего курса (лекции, видео, пособия), система строит по ним базу знаний, а студенты задают вопросы через Telegram-бота или HTTP API и получают ответ с ссылками на конкретные лекции и таймкоды.

## Как это устроено (коротко)

```text
Аудио/видео курса
      │
      ▼
Транскрибация (faster-whisper) ──► data/transcripts, data/segments
      │
      ▼
Разметка на смысловые блоки ──► data/drafts/*.draft.jsonl
      │
      ▼
Заполнение topic/summary/keywords ──► data/annotations/*.annotations.jsonl
      │
      ▼
Индексация (эмбеддинги + FAISS) ──► data/datasets/rag_index
      │
      ▼
Вопрос пользователя ──► гибридный поиск (вектор + лексика) ──► топ-5 фрагментов
      │
      ▼
Промпт (система + история + контекст + вопрос) ──► локальная LLM (LM Studio)
      │
      ▼
Ответ + автоматические ссылки на лекции с таймкодами
```

Подробное объяснение каждого шага, почему он устроен именно так и какие есть альтернативы — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Возможности

- **Транскрибация** аудио/видео через faster-whisper с таймкодами и (опционально) диаризацией спикеров.
- **Разметка** — сегменты объединяются в смысловые блоки, для каждого определяются тема, краткое содержание, ключевые слова и вопросы.
- **Гибридный RAG-поиск** — векторный поиск (FAISS) + лексический скоринг, с реранкингом.
- **Генерация ответа** любой instruct-моделью через локальный OpenAI-совместимый сервер (LM Studio, в будущем — vLLM). Модель **не фиксирована** — можно подключить другую (см. требования к модели ниже).
- **Автоматические ссылки на источники** — каждый ответ сопровождается списком лекций с таймкодами.
- **Короткая память диалога** на сессию (по `session_id` / `chat_id`).
- **API + Telegram-бот** поверх одного и того же движка.

## Требования к LLM-модели

Ассистент не привязан к конкретной модели — подойдёт любая instruct-модель, доступная через OpenAI-совместимый локальный сервер (LM Studio, vLLM, text-generation-webui и т.п.). Чтобы качество ответов не проседало, модель должна соответствовать минимуму:

- **Instruction-tuned** вариант (не base/completion-only) — промпт построен как системная роль + инструкции по формату ответа.
- **Не меньше ~3-4B параметров** — на меньших моделях заметно хуже держится формат ответа и качество русского языка.
- **Уверенная поддержка русского языка.**
- **Контекстное окно от ~8K токенов** — под системный промпт + до 5 RAG-фрагментов + историю диалога + генерацию ответа.
- **Квантизация не ниже Q4** (или аналог по битности) — более агрессивные квантования заметно бьют по следованию инструкциям.

## Быстрый старт

Подробная пошаговая инструкция (первый запуск, полный пайплайн от видео до готового бота, переменные окружения, типичные ошибки) — в [docs/SETUP.md](docs/SETUP.md).

```powershell
pip install -r requirements.txt

# 1. Запустить LM Studio с загруженной моделью и включённым Local Server
# 2. Положить видео/аудио лекций в data/raw/lectures и прогнать через пайплайн
python scripts/ingest_lectures.py
# 3. Запустить API
python scripts/server.py
```

В другом терминале — Telegram-бот:

```powershell
python scripts/bot.py
```

## Структура проекта

```text
Ai-assistant/
├── data/
│   ├── raw/               # исходные аудио/видео
│   ├── transcripts/       # результаты Whisper (человекочитаемые)
│   ├── segments/          # структурированные сегменты с таймкодами
│   ├── drafts/            # черновики блоков (промежуточные, регенерируемые)
│   ├── annotations/       # финальные аннотации: topic/summary/keywords/questions
│   ├── datasets/          # RAG-индекс (FAISS + метаданные)
│   └── outputs/           # результаты обработки
├── scripts/
│   ├── ingest_lectures.py                   # один скрипт: видео -> транскрипт -> аннотации -> индекс
│   ├── OpenAI-Whisper.py                    # транскрибация
│   ├── convert_to_wav.py                    # конвертация видео/аудио в WAV
│   ├── build_annotation_drafts_by_sentence.py # сегменты -> смысловые блоки (по предложениям)
│   ├── prefill_annotations.py               # блоки -> topic/summary/keywords
│   ├── embed_kb.py                          # построение RAG-индекса
│   ├── eval_rag.py                          # RAGAS-оценка качества RAG-пайплайна
│   ├── server.py                            # HTTP API
│   ├── bot.py                               # Telegram-клиент
│   └── chat_local.py                        # локальный CLI для проверки ответов
├── src/
│   ├── audio/          # транскрибация (faster-whisper, диаризация)
│   ├── rag/             # embedder, vector store, retriever
│   ├── llm/             # промпт, клиент LM Studio, форматирование ответа
│   ├── config.py
│   ├── logging_config.py
│   └── session_history.py
├── docs/
│   ├── SETUP.md          # подробная инструкция по запуску
│   └── ARCHITECTURE.md   # архитектура, технологии и почему выбраны именно они
└── requirements.txt
```

## Логи

Сервер, бот и модуль генерации пишут логи в `logs/app.log`: запросы, `session_id`, режим ответа, факт обращения к RAG, число найденных фрагментов, время ответа, ошибки.

## Минимальные требования

- GPU: 6-8 GB VRAM (зависит от выбранной модели и её квантизации);
- RAM: 16 GB;
- OS: Windows / Linux;
- Python: 3.11+.
